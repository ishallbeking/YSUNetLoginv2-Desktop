# Upstream source

This desktop extension is based on [KamijoToma/YSUNetLoginv2](https://github.com/KamijoToma/YSUNetLoginv2), commit `ee265154a000efbe9319fbf3406139d9cc54810f`.

Original author: SkyRain. The upstream Python client, original README, authorship metadata and notices are retained. The optional Go submodule is not included in this desktop source distribution.

This repository adds a Windows desktop UI, timed and offline reconnection, independent recovery guard, portable launchers and regression checks.
